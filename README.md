# VALORANT Stream Stats

A personal VALORANT stats overlay for Twitch, built with HTML and CSS and hosted using GitHub Pages.

## Features
- Transparent browser-source overlay
- Competitive rank display
- RR and match statistics layout
- Designed for Streamlabs Desktop

## Data and API
The current version uses demonstration data.
Live player statistics will only be added if supported by Riot Games' API access and authorization requirements.
